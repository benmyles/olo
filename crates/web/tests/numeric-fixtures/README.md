# Independent numeric ports

The 23 unmodified HTML resources and `numeric-testcommon.js` come from
[WPT](https://github.com/web-platform-tests/wpt/tree/d7bb5bb848fcd304c10669288a211dbafd106d90/css/css-values),
revision `d7bb5bb848fcd304c10669288a211dbafd106d90`, BSD-3-Clause
(`LICENSE.md`). `SOURCE.json` authenticates every imported/generated byte.

Run `/usr/bin/python3 crates/web/tests/numeric-fixtures/extract.py` to
reproduce `derived.json`. It ports literal input/reference strings and
literal for-of template environments. Known numeric/special-value/helper
wrappers are expanded from their pinned definitions, including invalid
helper fan-out. A rotate wrapper's argument is explicitly labelled as a
numeric angle port. It does not execute JS, CSSOM, a browser, an external
math engine, or Olo to generate expectations.

The native context records literal font sizes, line height, widths and
sequential style assignments from the resources. A small static element
model records the target's sibling index/count for these balanced fixture
documents; it is not a complete HTML parser or a test of tree-scoped CSS.
Otherwise, test defaults are explicit: em/rem 16px, viewport 1200×800px,
percentage basis 100px (or the recorded width/font-size), representative
ex/ch=0.5em, cap=0.7em, ic=1em and normal line height=1.2em. These are
provided numeric environments, not measured font metrics or layout. They
must not be presented as proof of a real style/layout host. Production
math resolution has no such defaults; missing host data is an error.

`support/math_fixtures.rs` independently decodes canonical numeric/unit
references, IEEE constants and the restricted two-term linear `calc(a + b)`
references. No engine parser/converter evaluates the reference. Comparisons
use each original `approx` tolerance where supplied, otherwise
`max(1e-6, abs(reference)*1e-7)`. Native special-value ports preserve the
helper's reciprocal/sign checks and infectious-NaN assertions. Integer
context ports round ties toward positive infinity. Invalid assertions
check the numeric grammar/type contract of the recorded property context,
not the full property grammar, range or declaration pipeline.

The denominator is 1,581 native ports plus five inventoried unported
property-limit helper calls: **1,586**. **1,572 pass**, **14 remain non-passes**:
six nonnumeric function/property wrappers, three specified/computed
serialization assertions and five property-limit helpers. `math_eval`
exits 1 while any remain; regression tests reject mismatches/errors/panics
and protect exact counts. This is a scoped native numeric corpus, not the
upstream WPT test count, full CSS math/property conformance, CSSOM or page
execution. Literal negative-zero behavior follows the pinned WPT arithmetic
assertions; top-level materialization censors its sign. No website passes
follow from these numbers.
