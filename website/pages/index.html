Free A desktop for Linux, in the spirit of BeOS

The desktop built for you and your agents.

Olo is a whole desktop written in Rust for Wayland. BeOS's yellow window tabs, Deskbar and Tracker, brought to 2026 with Rex for coding agents and the hosts they run on, Agent Screens they work on, Token Pool for the subscriptions they spend, your accounts in one place, and upgrades that keep every window open.

AI, Rex and integrations

A desktop made for coding agents, remote hosts and your accounts.

Agent-first as much as people-first: work across local and remote machines in Rex, give agents screens of their own, pool your subscriptions, and keep every account connected in one place.

Rex: sessions on any host, that outlive the desktop

Rex connects to local and remote Rex servers over sockets, native Rust SSH and Tailscale using libghostty-vt. Sessions live on the server, surviving reloads, laptop sleeps and roaming networks.

  • Built for slow links: predictive type-ahead safe around password prompts and full-screen TUIs, automatic static olo-rex-link deployment with no root, and optional UDP/QUIC transport behind SSH.
  • Account setup and carried settings: install Claude Code, Codex, Antigravity CLI and repos in one window, review settings diffs side by side with merge and remembered choices, and carry agent sessions across hosts.
  • Move to Another Host: migrate a working account in two parallel passes (including /var/tmp, leaving the source intact), resuming live agent sessions, moving Token Pool custody and keeping Go Back.
{{shot olo-rex | Rex: this computer and a host in its sidebar, a shell, a coding agent and a dev server in three panes}}

Child tabs, nested subagents and live transcripts

Rex knows when Claude Code, Codex or Antigravity is working, waiting for you, done or failed across every host, with notifications that jump straight to the pane and ⌘ J for the next waiting agent.

  • Child tabs without a desktop: olo agent starts subagents or commands as nested child tabs on the host's own agents service, with zero-polling cursor watches (olo agent watch) and semantic approvals (olo agent approve). Close your laptop and they keep running.
  • Streaming Transcript viewer: switch any agent pane between raw terminal output and turn-grouped prose with collapsible tool calls, inline Find and Follow.
  • Keep It Going and Auto Approve: nudge an idle agent after two quiet minutes at its prompt, or count down thirty seconds, with a Stop button, before a permission or folder-trust question is answered. It never approves a plan, and it is yours to turn on.
{{shot olo-rex-agents | Rex's Activity: an agent with its child agents under it, and its transcript with a tool call opened}}

Olo Desktop Bridge and per-host permissions

Inside any remote Rex session, the olo command reaches back to your desktop, and optionally shims xdg-open, notify-send, wl-copy and op. All eight permissions start off for remote hosts and are granted per host in Preferences ▸ Rex ▸ Hosts.

  • Links, ports and live folder sync: olo open auto-forwards remote localhost URLs or opens remote files locally; olo forward keeps ports alive across upgrades; olo sync runs zero-polling two-way folder sync with conflict copies; Tracker browses any host at rex://HOST/PATH.
  • Passwords, SSH keys and clipboard: answer olo op from your desktop vault without copying secrets to the server, or lend SSH keys per host.
  • Guarded olo run: remote sessions can ask to run a command on your desktop, gated by an explicit Deny-default approval sheet with a half-second guard and live output streaming.

Agent Screens: headless 120 Hz desktops of their own

Every Olo window, Chrome tab and GTK/Qt app can be read as structured widgets and driven through a documented API, on full headless Wayland desktops that never move your pointer or steal your focus.

  • Watch live and Take Control: zero-copy GPU viewing, ⌘ K to take over while locking out agent actions, full action History, frame-tile Recorder scrubbing and hardware-encoded MP4 video export.
  • Structured, not just pixels: Olo kit trees, Chrome DOM across cross-origin iframes with covered-element checks, and AT-SPI. Share specific Passwords entries and passkeys read-only per screen.
$ olo-screen start
$ olo-screen run agent olo-styled-edit notes.md
$ olo-screen tree agent --role Button
$ olo-screen click agent --role Button --name Save

Terminal built for local coding agents

Shells live in olo-termd so desktop reloads never close them, paired with Olo's bundled Rust shell (brush) and on-device SIMD command suggestions (olo-complete).

  • Repo tab groups and in-process worktrees: create, rename and remove Git worktrees through libgit2 from a tab's menu, with live GitHub pull request and check badges per tab.
  • Agent-kept titles and startup context: Claude Code and Codex update their own tab titles via MCP and receive their group's worktrees on launch, all opt-in under Preferences ▸ Terminal.
  • Keep It Going, Auto Approve and olo-sudo: keep overnight runs moving and approve headless sudo requests in a native Olo window.
{{shot olo-terminal-agents | Terminal: a tab group for a feature, each tab titled by the coding agent working in it}}

Token Pool: shared subscriptions across machines

Pool multiple Claude and ChatGPT subscriptions across Claude Code and Codex in one unified window (Accounts, Activity and Machines), routing earliest-expiring quotas first with client-identical requests and zero-gap handover across upgrades.

  • Standalone remote host pools: deploy olo-pool-host over SSH so agents on remote Rex servers keep drawing from the pool even while your desktop is off, with single-keeper refresh-token custody.
  • Live quotas in Deskbar: keep per-account bars or multi-quota heatmaps right beside your CPU and GPU meters.

Your accounts in one place, and AI where you ask for it

Connect your accounts once in Preferences ▸ Integrations across five tabs (Google, Fastmail, CalDAV, GitHub and Telegram), and choose your models in Preferences ▸ AI.

  • Several Google accounts, each set up for you: tick Mail, Calendar and DiskBackup per account; adding one has Claude Code make the account's own Google Cloud app, on an Agent Screen you can follow.
  • AI in a few places, each one you can turn off: /ask in the Command Palette (aware of your active Terminal), ⌘ ↩ emoji suggestions, Weather's forecast assistant highlighting time windows on charts, and Calendar's assistant drafting events that wait for your confirmation.

The desktop

Familiar the moment you see it. Quick the moment you touch it.

Deskbar, Glances and Tracker

Deskbar sits top-right on every display (Olo menu, clock with upcoming Calendar events, rich tray and per-workspace apps) and folds to a corner button (⌃ ⌘ D) so tiled windows take its room. Tracker handles local folders, archives and remote Rex hosts alike.

  • Live widgets and App Glances: pin CPU, memory, GPUs, disks, network, temperatures, power and Token Pool meters with hover top-five process cards, plus Glances for Notifications, Weather, Calendar, To-Do, Kache and Rex.
  • Spatial folders, archives and backups: Icon, List and Column views, Quick Look previews, in-window zip/tar/7z/RAR/ISO archives, and DiskBackup ticks with Older Versions.
  • Remote Rex folders: browse any Rex host natively in Tracker at rex://HOST/PATH over its existing SSH link.

A command palette for everything

Press ⌘ Space for apps, the front app's menu commands, individual Preferences settings (spotlighting the exact control), windows, Rex sessions and panes, Passwords, Calendar, To-Do, paths, sums, /ask AI answers and /ws web search, ranked by an on-device neural model.

Keyboard hints put a jump letter on every control in every window, so anything you can click, you can reach from the keyboard.

Workspaces, Overview and seven auto-tiling layouts

Per-display workspaces, an Overview of them all, Twitcher (⌘ Tab) with display columns, tabbed window groups, and three windowing modes per workspace: Standard, Focus and Auto-Tiling.

  • Seven auto-tiling layouts: Main and Stack, Halves, Columns, Rows, Grid, Spiral and horizontal Scrolling, with synchronised frame-matched edge drags, Scratchpad, per-app tile pinning and Undo Window Arrangement (⌃ ⌘ Z).

Pixel-exact at 1×, 1.25×, 1.5×, 1.75× and 2×, with light, dark and night modes, HDR with wallpaper gain maps, variable refresh rate, and multi-GPU output keeping the discrete GPU asleep at rest.

Your phone, natively over Bluetooth

Pair an iPhone or Android phone over Bluetooth with nothing installed on the phone and no cloud account in between. Olo speaks MAP, PBAP, ANCS and HFP in process.

  • Messages, contacts, calls and music: read and reply to conversations, browse contacts, handle calls and control phone audio right from your desktop.
  • One-time codes where you need them: verification codes from SMS or email are offered in the waiting browser tab, or in an agent's tab with your approval.
  • Watched: reconnects automatically, and Olo Doctor reports and repairs Bluetooth snags.

Fast and light

Rules, not hopes.

Speed isn't added at the end. Olo holds every change to four rules, and measures it against them.

1

Idle costs nothing

No polling, no frames or events when nothing changed, and large resting windows drop their GPU swapchains after thirty seconds. Work follows what changed, not what's on screen.

2

Never block the UI

Anything that can take more than a frame runs on a worker thread, shows live progress, streams its results and can be cancelled.

3

Measured, every time

Every change to what runs per frame, per event or at rest is measured on release builds before and after, latency included, and the numbers go in its commit.

4

Pixel-perfect at every scale

Checked in light, dark and night at 1×, 1.25×, 1.5×, 1.75× and 2×. Nothing drawn from a bitmap is resampled: one texture pixel to one device pixel.
