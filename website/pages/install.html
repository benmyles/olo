--- title: Install Olo Desktop description: Install Olo on Fedora 44 or 45 Workstation with one program, beside GNOME, or build it from source. How to update, and what the Installer does. ---
Install

Olo on your computer, in minutes.

One program installs Olo beside GNOME, which stays as it is. You choose Olo or GNOME each time you log in.

{{shot olo-installer | Olo's Installer: one full-screen program, after BeOS's own}}

What you need

  • Fedora 44 or 45 Workstation, x86_64. (To build from source: Workstation or an atomic desktop such as Silverblue, on x86_64 or aarch64.)
  • Your password, once: the Installer adds what Olo needs from Fedora.

With the Installer

Download the Installer from the latest release and run it:

$ curl -LO https://github.com/benmyles/olo/releases/latest/download/olo-installer-x86_64
$ chmod +x olo-installer-x86_64 && ./olo-installer-x86_64

The Installer is one full-screen program, after BeOS's own: agree to the licence, then click Begin.

  1. It installs what Olo needs from Fedora.
  2. It downloads Olo and checks it.
  3. It puts Olo in your home folder (~/.local) and adds it to the login screen.
  4. If you like, it also installs Olo's own login screen and boot splash, and RPM Fusion.

Then log out, and choose Olo Desktop from the login screen's session menu (the gear by Sign In) before you log in again. Fedora's GNOME stays there too.

Updating

Run the Installer again: it keeps what you chose and brings everything up to date. Olo upgrades in place: the running desktop is replaced without closing a window, and your apps come back as they were.

From source

To build Olo yourself:

$ git clone https://github.com/benmyles/olo && cd olo && tools/setup.sh

tools/setup.sh installs what's missing (compilers, libraries, Rust, Git LFS, drivers), builds Olo into ~/.local/bin and adds it to the login screen. Run it again any time: each step only does what isn't done yet.

After a git pull and a build, Deskbar offers the new build in its tray, and its Upgrade installs it and reloads the running desktop in place.

Then

  • Press ⌘ Space for the command palette, and type what you're after.
  • Open Preferences ▸ Themes to choose Classic or Platinum, and Backgrounds for a wallpaper.
  • If something gets in Olo's way, Olo Doctor finds it and fixes it with a button.
  • Want to help? Start with Hacking on Olo.
