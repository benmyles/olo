Brand

The Olo brand.

A glossy ring in Olo blue and Olo yellow, and a name set in Sora. Here is everything you need to write about Olo or link to it.

Logos

The horizontal logo is the primary one. Use the stacked logo where the space is square, and the mark alone where Olo's name is already said nearby. Each comes for light and dark backgrounds, as transparent PNGs.

Typeface

Olo's typeface is Sora, a geometric sans under the SIL Open Font License, shipped with Olo. "Olo" is set in ExtraBold with its l a plain bar; "DESKTOP" in SemiBold, tracked wide (320), as wide as the name above it.

Using them

  • Leave space round the logo, at least the height of the "O".
  • Use the logos as they are: don't recolour, stretch, outline or add effects to them, and don't redraw the wordmark in another typeface.
  • On a dark background, use the versions made for dark.
  • Write the name as Olo, or Olo Desktop in full.
